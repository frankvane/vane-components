## 二、脚本的五条防假阳/防漏检规则（都是踩出来的）

1. **背景逐层合成**（`resolveBg`）：半透明底色 `rgba(...,.12)` 若当成不透明色，
   会算出「accent 字 vs accent 淡底 = 1:1」——card 一次误报 565 处。
2. **祖先链 opacity 乘进来**（`opChain`）：常见写法是「整卡 `opacity:.6`」，
   只看文本元素自己是 1，会漏掉。
3. **文字自身 alpha 也乘**：`color: rgba(...,.6)` 同样压对比度。
   ⚠️ 报告里的 `fg` 只留 RGB，必须连带 `fgAlpha` 落盘，否则看起来就是
   「#1c1a17 压 #fbfaf7 怎么会 4.48」——实际是 `rgba(28,26,23,0.6)`。
4. **`aria-hidden="true"` 子树跳过**（记入 `deco`），`sr-only`（1px + clip）同样跳过。
5. **`background-image`（照片/渐变）跳过**（记入 `unknown`）：底色不可判定，不猜。
6. **动画钉到终态**：`d.getAnimations({subtree:true}).forEach(a => a.finish())`。
   不钉的话，同一次扫描里 0.57 与 0.98 会混在一起，得出一堆并不存在的低对比度
   （lazy-image 因此虚报 3191 处）。

## 三、六类真问题（都是通用模式）

| # | 模式 | 典型值 | 修法 |
|---|---|---|---|
| 1 | **浅色舞台用 opacity 压字**（最主要） | `#999 @1` 2.85 / `#8a8a8a` 3.45 / `#c8c8c8` 1.67 / `#ffc107` 1.63 | 去 opacity，换成实色；需要「弱化」就换 token 而不是降不透明度 |
| 2 | **深色令牌落到白卡** | `--faint #8b9080` 白底 3.5 | 白卡里不许用深色主题令牌；或给白卡补自己的墨色 |
| 3 | **组件根节点没写 `color`**（ADR-13 第 5 条） | sku `1.17:1`、profile tab 栏 `2.66:1`、comment `2.8–3.7:1`、lazy-image 占位 `1.07:1` | 内联了背景就必须内联字色，容器同理 |
| 4 | **彩色底 + 白字** | 金色徽章 1.4 / 橙「库存紧张」2.16 / 绿徽标 2.78 / CSV `option` 白字压白底 1:1 | 底色压深一档（`#FFD700→#8a4d00`、`#FF5722→#c4390f`…）或按底亮度选字色 |
| 5 | **`aria-hidden` 装饰被当正文** | 星级 ★ | 补 `role="img"` + `aria-label`，把评分语义移到容器 |
| 6 | **oneDark 注释色 `#5c6370`** | 暗底 3.17 | 提到 `#8b93a1`（5.6:1），观感仍是「灰的」 |

另外两个结构性坑：

- **反色面板的「空态」漏给色**：日志面板底 `var(--text)` / 字 `var(--text-inv)`，
  空态却写 `var(--text-2)` → 奶油压奶油 1.76:1。**反色容器的子节点必须按反色给字。**
- **纸面组件被放进暗面板**：file-preview 的 `.map-row` / `.version-row` 按纸面配色写
  （深墨 + 白底），搬到 `--surface #121110` 上就成 1.09:1。

## 四、本轮的两处「不是调色」的修法

- **水印**（`WatermarkPlugin`）：opacity 是产品特性，不能为了过线把它拉满。
  WCAG 1.4.3 对「属于含有其他重要视觉内容的图片的文字」明确豁免 → 改为
  `aria-hidden="true"`（读屏不该在 alt 之后再念一遍水印），并修掉真 bug：
  原来的 `textShadow` 是**白色**光晕，白字 + 白晕压在浅图上字直接糊掉，改成暗色描边。
- **第三方写死的颜色**（`react-xml-viewer` 折叠指示符 `#777`）：theme 里没有开关，
  只能用属性选择器盖内联样式：
  `.rxv-container span[style*="rgb(119, 119, 119)"] { color:#8b93a1 !important }`，
  只匹配这一个色值，语法高亮不被波及。

## 六、给下一位的提醒

- **别用截图验收对比度**。截图看不出 4.48 与 4.51 的差别，也看不出「因为 CSS 没加载所以像白底」。
  先跑体检，再看截图。
- **`demos/` 是非破坏式聚合**：旧 hash 资源会留着，`index.html` 才指向新产物。
  判断「改了没生效」时先看 `index.html` 引用的文件名，别被同时存在的旧 chunk 误导。
- **浏览器标签跑久了会挂**（113 页的 iframe 循环）。表现为「脚本不报错也永不回传」，
  换一个新标签页即可，别去改脚本。
