## 二、新版应用架构

### 2.1 数据层 `demo/src/data/plugin-catalog.ts`（核心）
- `Category` 枚举（ecommerce / interaction / visual / perf / robust / viewport / a11y / other）+ `CATEGORY_LABELS`。
- `META`：73 个插件目录 → `{ category, title }` 显式映射（中文展示名）。
- `slugify(dir)`：`XxxPlugin` → kebab slug（如 `SkeletonPlugin`→`skeleton`），用于 `/plugin/:id`。
- `PLUGINS`：用 `import.meta.glob("../../src/custom-plugins/*/doc.json", { eager:true, import:"default" })` 动态加载包内 **73 个** doc.json，`factoryName = "create" + doc.name`。
- `PLUGINS_BY_CATEGORY`、`getPluginById`、`getPluginFactory`（用 `(VL as any)[meta.factoryName]` 取工厂）。
- `COMBOS`（9 项）、`ADVANCED`（4 项）静态数组。

### 2.2 组件 `demo/src/components/`
- `CodeBlock.tsx`：`react-syntax-highlighter` Prism + `oneDark`，统一源码高亮（最小用法 / 多场景 / 源码 / 组合代码）。
- `DemoLayout.tsx`：轻量页面壳（具名导出 `export const DemoLayout`），替代旧 `DemoPage`，props `{ title, description?, source?, children }`。
- `ConfigControls.tsx`：基于 doc.json `config` 启发式生成控件（enum→`<select>` / boolean→checkbox / number→`<input type=number>` / string→text）。
- `PluginPreview.tsx`：实时预览，错误边界包裹；`withPlugins(LazyLoadImageCore, [factory(cfgValues)])`；工具栏含图片 URL 输入 / 「使用失效 URL（演示错误态）」复选框 / 重置。
- `Sidebar.tsx`：`GROUP_ORDER`（ecommerce→interaction→visual→perf→robust→viewport→a11y→other），电商核心 / 视觉效果与交互用 `GRADIENT` 渐变高亮；应用级入口 `/`、`/scenarios`、`/workshop`；底部 组合示例 / 高级功能 分组。

### 2.3 页面 `demo/src/pages/`
- `Home.tsx`：欢迎语 + 4 特性卡（参数设置 / 配置项 / 场景示例 / 插件工坊）+ 按分组浏览卡片网格。
- `PluginDetail.tsx`：`useParams<{id}>` → `getPluginById`；左栏 `PluginPreview`、右栏 doc.json 配置表 + 用法 `CodeBlock`（用 `meta.factoryName` + `meta.example`）。
- `CombosPage.tsx`：`React.lazy(() => import("../combos/XxxDemo").then(m => ({default: m.X})))` 映射 9 个组合；列表 + `/combo/:id` 详情。
- `AdvancedPage.tsx`：同结构，4 个高级示例 lazy。
- `ScenariosPage.tsx`：内联 `EcommerceGrid`（缓存+骨架+淡入+兜底图）+ 3 个 `React.lazy` 场景（`LazyVertical`/`LazyHorizontal`/`LazyGrid`）。
- `WorkshopPage.tsx`：左栏按分组勾选插件 + 右栏实时 `withPlugins` 预览 + 组合代码 `CodeBlock`。

## 七、排错经验沉淀（本轮回合）

- TSX 内联对象类型 `React.FC<{ id: string }>` 被解析器误判为 JSX（TS1005）→ 改用命名 `interface IdProps { id: string }`。
- 具名导出页面无 default（TS2322）→ lazy 用 `.then(m => ({ default: m.X }))` 映射；`useParams<RouteId>` 不满足约束（TS2344）→ 改 `useParams()`（无泛型）。
- 抢救文件旧 `import DemoLayout from` 默认导入（TS2613）→ sed 改具名 `import { DemoLayout }`。
- advanced 示例 import `SandboxConfig`/`wrapPluginHook`/`DependencyResolver` 报 no exported member → 根 `src/index.ts` 加 `export * from "./advanced"` + 重建 dist（`pnpm --filter vane-lazy-image build`）。
- Vite `nohup` 后台启动被回收返回 502 → 改用工具 `run_in_background` 机制直接启动 vite，curl 确认 200。
- safe-delete fail-closed 拦截 `rm -rf originals`（genie-trash 后端失败）→ 内容抢救后 `mv originals /c/tmp-originals-trash-20261025` 移出仓库。
