# 场景示例板块 · 重构方案（待确认）

> 目标：把 `场景示例` 从「1 个电商网格 + 3 个虚拟滚动」升级为**按行业分类的真实业务场景复刻**，
> 每个场景都给出「可运行预览 + 可直接复制的完整源码」。
>
> 参照站点：影视点播 `olehdtv`、电商 `jd.com`、视频社区 `bilibili` / `youtube`，并补充同类型的
> 图库、社交、资讯、后台、出行、弱网、营销共 10 类。

---

## 0. 一个必须先对齐的口径

**不做内容复刻，只做版式复刻。**

- 参照站点的图片带防盗链 / 版权 / CORS 限制，直接引用必然裂图，也违反站点条款。
- 因此每个场景复刻的是**那一类页面真实的布局与插件分工**：
  - 京东搜索结果 → 双列商品卡、1:1 主图、价格行、促销角标、骨架占位；
  - B 站首页 → 16:9 封面栅格、右下角时长胶囊、播放量、悬停起播；
  - VOD 站 → 2:3 竖版海报墙、一行 5-6 张、选集横滑。
- 图片源用 `picsum.photos` 固定 seed（保证可重复、可截图取证）/ 本地占位，版式与间距照抄。
- 页面上每个场景卡都明确标注「版式参照：jd.com 搜索结果页」，不冒充实站截图。

## 1. 页面结构改造

```
场景示例
├─ 顶部：分类 Tab（10 类，带场景数徽标）+ 一句该类业务的加载矛盾
├─ 场景卡（每类 3-5 张）
│  ├─ 左栏：实时复刻（真版式，可交互，失败可重放）
│  └─ 右栏：
│     ├─ 插件装配（组合式，一行一个插件 + 为什么用它）
│     ├─ 源码 A：最小可用版（10-15 行，只要装配，样式靠库默认）
│     └─ 源码 B：完整版（假数据 + 样式 + 错误分支，整段可粘贴）
└─ 每张卡右上角：「在插件页打开 →」跳到用到的核心插件详情页
```

**源码可复制** 需要两件基础设施，当前都缺：

1. `CodeBlock` 加「复制」按钮（`navigator.clipboard` + 失败回退 `execCommand`），并给复制成功一个 1.2s 的态。
2. 场景源码抽到 `demo/src/scenarios/registry.ts`，**预览组件与展示源码同源**（`?raw` 导入同一份文件），
   避免「示例代码与实际渲染不一致」这种最容易掉分的问题。

## 3. 源码规范

每个场景产出两份代码，都从 `registry.ts` 单一来源注入：

```tsx
// A. 最小可用版（复制即用，不依赖演示站任何东西）
const PosterWall = withPlugins(LazyLoadImageCore, [
  createPriorityLoadingPlugin({ firstScreenCount: 2 }),
  createAspectRatioSpacerPlugin({ ratio: "2/3" }),
  createBlurUpPlugin({ blurRadius: 12 }),
]);

<PosterWall src={poster} alt={title} loading="lazy" />
```

```tsx
// B. 完整版：含假数据、样式、失败分支（整段可跑）
type Item = { id: string; title: string; poster: string };

export function PosterWall({ items }: { items: Item[] }) { ... }
```

约束：

- 只用 `vane-lazy-image` + `react`，不引入 antd / tailwind，复制到任何项目都能编译。
- 类型完整（`tsc --noEmit` 必须 0 错），不留 `any`。
- 每份源码首行注释写明「版式参照：xxx，用途：yyy，包含插件：nnn」。
